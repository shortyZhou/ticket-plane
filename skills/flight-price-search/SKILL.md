# 四平台机票查询

先从用户要求或上下文确定：出发地与可接受机场、目的地与可接受机场、去程日期和起飞时段、是否往返、返程日期和起飞时段、人数、舱位、直飞或中转要求。日期和时段是每次查询的输入；本 skill 不预设任何航线或出行时间。缺少影响搜索的条件时询问用户，其余条件按用户意图合理处理并标明。

每次从平台当时可访问的搜索结果重新查询。仅把可确认的航班和报价写入结果，记录各平台查询时间、搜索链接、页面标价口径及访问状态。搜索摘要、历史工作簿和此前聊天只用于理解流程，不能代替本次报价。

## 单程

在四个平台分别按相同旅客、舱位、日期和机场条件搜索，筛选用户指定的**起飞**时段。记录航班号、承运或共享航班关系、出发与到达机场、起飞与到达时间、直飞或中转、页面起价。按实际承运航班及时间核对代码共享；同一物理航班可分别展示多个航班号，但不要把它们误当成不同班次。平台未显示某个航班号时，该平台价格留空，不能把共享航班的报价擅自移填过去。

## 往返组合

必须进入每个平台的**往返**搜索页。对每个符合条件的去程逐一选择，再查看符合返程时段的返程及其对应组合报价；换一个去程后重新核对返程价格。仅对页面实际显示的去返航班组合填价，不用两个单程报价相加，也不用最低价日历的数字冒充具体组合价。若用户要求所有组合，应覆盖当次页面可访问的全部符合条件组合，并说明未覆盖的分页、筛选或登录限制。

- **携程**：单程可使用当前环境中可用且已验证的 OpenCLI `ctrip flight` 命令读取列表，再与搜索页信息核对；该命令输出通常是列表首个报价。往返在携程往返页选择去程后，读取返程列表对应的“往返总价”。OpenCLI 的单程结果不能推导往返价。
- **飞猪**：从飞猪单程或往返搜索页读取航班列表。往返须选定去程并进入返程或票档页面，看到具体组合总价后才填价。若跳转登录页、验证码页或页面未给出组合价，记录该限制，价格留空。
- **同程**：从同程单程页读取该航班的页面“起”价。往返先选择去程，再读取返程列表中对应组合的“起”价；不得沿用去程列表价。
- **去哪儿**：可使用可访问的网页或触屏版搜索页。往返先确认所选去程及页面显示的往返基础起价，再读取返程行的“补”价；两者相加得到该页面组合报价，并尽可能与页面底部总价核对。若基础价与补价的对应关系或底部总价无法核实，留空并说明。

页面结构和字段可能变化。上述价格读取方式只在本次页面确实展示对应信息时适用；若显示新的计价方式，以当前页面可核实的组合总价为准并说明口径。需要登录时可让用户在其浏览器完成登录，再继续读取；不要索取密码或绕过验证码。

## 交付与核验

在聊天中用表格列出查询到的航班及各平台价格。单程表按同一航班和时间对齐平台；往返表按同一去程、返程组合对齐平台。表格过长时可分段展示，但用户要求完整结果时不能只给最低价。若要求 Excel，可分别建单程与往返工作表，并在表中保留查询时间、来源链接、价格口径、空价原因；保存后检查工作表、组合数量和代表性报价。

统一称“页面起价”或平台实际用语，除非结算页证实，否则不称最终支付价或含税价。行李额、退改条件、具体票档和税费未核实则写“未知”。连接失败、登录失效、验证码、超时或页面无法加载时写明具体错误，不推断为无票。各平台可独立交付，失败的平台留空并解释。
